# Trading PRO — Android

Projeto Android que empacota a versão mobile do Trading PRO em uma WebView local segura, com:
- nome do app: Trading PRO
- ícone de lançamento
- splash screen Android 12+
- orientação retrato
- acesso à Internet para a integração do painel
- conteúdo HTML/JS local em `app/src/main/assets`

## Abrir
Abra esta pasta no Android Studio e aguarde o Gradle sincronizar.
Depois execute `app` em um aparelho/emulador ou use **Build > Generate App Bundles or APKs > Generate APKs**.

O ambiente de criação desta entrega não possui Android SDK/Gradle instalado, então o APK assinado não foi compilado aqui; o projeto está pronto para compilação no Android Studio.
